- [**Python.org**](https://www.python.org/): The official website for the Python programming language.
- [**Installing Python**](https://www.python.org/downloads/): Official guide to install Python.
- [**Project Jupyter**](https://jupyter.org/install): An open-source project that provides a web-based interactive computing environment for creating and sharing documents.
- [**PyPI**](https://pypi.org/): The Python Package Index, a repository of software packages for Python.
- [**GitHub**](https://github.com/): A web-based hosting service for version control and collaboration.
- [**Pandas Documentation**](https://pandas.pydata.org/pandas-docs/stable/): The official documentation for the Pandas library.
- [**NumPy Documentation**](https://numpy.org/doc/): The official documentation for the NumPy library.
- [**Matplotlib**](https://matplotlib.org/): A popular library for creating visualizations in Python.
- [**SciPy Documentation**](https://docs.scipy.org/doc/): The official documentation for the SciPy library.
- [**Poetry**](https://python-poetry.org/): A tool for dependency management and packaging in Python. It allows you to declare the libraries your project depends on and it will manage (install/update) them for you.
- [**Conda**](https://docs.conda.io/en/latest/): An open-source package management system and environment management system that runs on Windows, macOS, and Linux.
