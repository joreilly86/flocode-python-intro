# Python for Engineers | Intro Course

This is an introduction to Python for Engineers. This is the first module in Flocode’s - Intro to Python Course, intended to show engineers just how much they can achieve through the Python programming language. If you’re curious about Python and how it can be leveraged to accelerate your engineering career, you’re in the right place. 

So let’s jump in and explore this fascinating topic.

## About

Let’s start with explaining the course, what it is and who it’s for.

- No prior coding experience is necessary. This course is designed specifically for engineers new to programming.
- I will provide a high level overview of Python and it's relevance to engineering, in my case specifically this includes aspects of civil, structural and geotechnical engineering but of course these principles will apply broadly to all engineering disciplines.
- You’re busy, of course, we get it. Flocode courses are designed to contain the essentials. Sequentially ordered to give you exactly what you need. Much of the learning within flocode is based on promoting and instilling programmatic thinking. Of course we will learn about the nuts and bolts of Python, but this is a long term pursuit and It’s all about building the momentum you need to continue your own journey. Learning any new skill, especially one as complex and obtuse as programming is difficult and my role in this process is to make it as efficient and painless as possible.
- By the end of this course, I want you to understand the value proposition of learning Python and ultimately feel ready to continue your learning journey.

## Who am I?

My name is James O'Reilly, I’m a Structural Engineer with extensive experience in diverse, multidisciplinary engineering projects worldwide. I have Master’s degree in Advanced Structural Engineering from Edinburgh Napier University, Scotland. Over the last 14 years I’ve worked on a variety of heavy civil projects in the Energy, Water, Bridge, Mining, and Marine sectors. Over the last 6 years, I have adapted my workflow to lean more heavily on Python and other open-source tools for a broad variety of engineering projects and tasks, examples of which I will share later.

## Overview

Before we get into the weeds, we need some context.

Python's significance in today's engineering landscape is rapidly increasing. It's a powerful tool that streamlines workflows, enhances data analysis, and opens new avenues for innovation in design and problem-solving. While it’s still underutilized in traditional engineering settings, a growing number of forward-thinking firms are beginning to embrace Python.

Its use in automating calculations, control software and report generation is becoming standard within many consultancies, demonstrated by its integration with industry software leaders like Revit, ANSYS, CSI, Rhino, and many more.

The use cases explored in the flocode curriculum are based on my own experience using Python and will provide a broad foundation in the language using different examples, which will empower you to build custom tools tailored to your specific engineering challenges and workflows.

# What does learning Python involve?

Adapting Python for professional engineering requires proficiency in three core areas:

- Jupyter Notebooks
- Scripting
- Building applications.

This a simplification of course, there is much to learn in the space between these topics but generally speaking, this is how I approach it.

Understanding these tools and techniques is essential for streamlining engineering workflows and problem-solving. But before you can really implement anything practically in Python, you need to do some groundwork in terms of understanding the fundamental syntax or structure of the language. This is relatively straightforward in terms of computer programming principles but it can be a significant mental workload for somebody with a demanding engineering workload, which is presumably why you may be watching this video. 

Making the space for yourself to learn Python is a serious part of the process.

So let’s talk about Flocode’s plan for course material. There are many topics to cover and the breadth of possibilities is wide. As such, the best way to teach Python is through a fundamentals first, principles based approach. We'll cover a diverse range of use cases across different engineering disciplines, offering bite-sized challenges that solidify your understanding with each step.  

As you progress through Python's core syntax and control flow, complexity of the examples will gradually increase, ensuring you're constantly building valuable skills and fitting the puzzle pieces together.

As we progress through the curriculum in Flocode’s courses, we will delve into aspects of:

- Structures
- Hydraulics
- Geotechnics
- Data Science
- Automation
- Tool Development

The list goes on but rest assured, it is comprehensive and steadily growing.

That about covers it for this quick intro. Next we'll talk specifically about why engineers should learn Python and the best way to approach it. Thank you for your time and I'll see you in the next one.
